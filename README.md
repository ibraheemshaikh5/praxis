# Praxis

Praxis is a personal life operating system: one calm place to plan each day, keep
long-running priorities visible, and manage the information and workflows that
support a well-lived life.

It begins as a responsive web app for computers and phones. The product will grow
vertical slice by vertical slice, with mobile and desktop apps considered after
the web experience is dependable.

## Product principles

- Calm by default: today stays focused and uncluttered.
- Connected: daily actions can support goals, life areas, applications, or learning.
- Durable: important context should not disappear inside old daily notes.
- Private and portable: data can be exported, backed up, and owned by the user.
- Assisted, not controlled: agents suggest and automate with clear approval.
- Expandable: new modules share a stable core instead of becoming separate tools.

## First slice

Build the Daily Planner as an installable responsive web app:

- Open directly to today.
- Add, edit, complete, reorder, and reschedule items quickly.
- Move unfinished items forward intentionally.
- Browse previous and upcoming days.
- Use real dates automatically instead of maintaining a weekly note template.
- Preserve a distraction-free keyboard and touch experience.
