# Praxis roadmap

Build and release one useful vertical slice at a time.

## 0 — Foundation

- [ ] Record product scope, non-goals, and success measures.
- [ ] Choose the web stack and document key architecture decisions.
- [ ] Create a responsive, installable PWA shell.
- [ ] Establish a modular monolith with clear module boundaries.
- [ ] Model shared concepts: items, dates, tags, links, notes, and attachments.
- [ ] Add typed validation, migrations, tests, linting, and CI.
- [ ] Add secure sign-in and private-by-default data access.
- [ ] Add backups, export, restore, logging, and error monitoring.

## 1 — Daily Planner

- [ ] Generate today and its date automatically.
- [ ] Add, edit, complete, delete, reorder, and undo planner items.
- [ ] Reschedule items or carry unfinished work forward.
- [ ] Navigate past and future days.
- [ ] Add an inbox for items without a date.
- [ ] Support notes and lightweight item grouping.
- [ ] Add fast keyboard controls and polished mobile interactions.
- [ ] Add recurring items and reminders.
- [ ] Add a weekly review and planning view.

## 2 — Goals

- [ ] Create long-running goals with outcomes and target dates.
- [ ] Break goals into milestones and next actions.
- [ ] Link daily planner items to goals.
- [ ] Show progress, recent activity, and stalled goals.
- [ ] Add goal check-ins and review history.

## 3 — Life Areas

- [ ] Create areas such as health, learning, career, and relationships.
- [ ] Define what improvement means for each area.
- [ ] Track habits, measures, notes, and progress over time.
- [ ] Link goals and daily actions to an area.
- [ ] Add recurring area reviews.

## 4 — Internship Applications

- [ ] Record company, role, link, location, source, and notes.
- [ ] Track status, dates, contacts, interviews, and follow-ups.
- [ ] Add deadlines, reminders, filters, and a pipeline view.
- [ ] Import from and export to the existing Google Sheet.
- [ ] Add optional two-way Google Sheets sync with conflict handling.
- [ ] Track application outcomes and useful metrics.

## 5 — Literature

- [ ] Track books and novels: planned, reading, finished, or paused.
- [ ] Record reading progress, thoughts, highlights, and takeaways.
- [ ] Organize works by author, genre, topic, and date.
- [ ] Generate optional comprehension questions and quizzes.
- [ ] Review learning across a book, category, or time period.

## 6 — Articles

- [ ] Save an article with source, author, date, topic, and reading status.
- [ ] Capture notes, claims, questions, and takeaways.
- [ ] Connect related ideas in a browsable knowledge graph.
- [ ] Ask questions grounded in saved article content.
- [ ] Generate quizzes by article, category, period, or milestone.
- [ ] Track review and retention over time.

## 7 — Informative Videos

- [ ] Save videos with channel, topic, duration, and watch status.
- [ ] Capture notes, timestamps, takeaways, and questions.
- [ ] Connect videos to goals, areas, articles, and books.
- [ ] Generate grounded summaries, questions, and review quizzes.

## 8 — Shopping

- [ ] Capture things to research, shop for, or buy.
- [ ] Track priority, budget, options, links, and purchase status.
- [ ] Group items by need, project, store, or life area.
- [ ] Record final decisions and purchase history.

## 9 — Agents and Automation

- [ ] Add a shared assistant interface across Praxis modules.
- [ ] Let agents propose planning, review, research, and follow-up actions.
- [ ] Require approval before consequential or external actions.
- [ ] Show sources, reasoning summaries, tool activity, and an audit history.
- [ ] Add module-specific agents with narrow permissions.
- [ ] Add scheduled reviews and user-controlled automations.
- [ ] Evaluate agent quality, cost, latency, privacy, and failure recovery.

## 10 — Native Experiences

- [ ] Make the PWA reliable offline with safe synchronization.
- [ ] Evaluate native mobile apps after the mobile web workflow is proven.
- [ ] Evaluate a desktop app after desktop-only needs are clear.
- [ ] Add notifications, share targets, widgets, and quick capture where useful.

## Always

- [ ] Keep accessibility, responsive design, and performance in the definition of done.
- [ ] Test migrations, permissions, sync, time zones, and destructive actions.
- [ ] Keep data portable and integrations replaceable.
- [ ] Document decisions and keep modules independently understandable.
- [ ] Measure whether each feature reduces friction or improves follow-through.
